Abstract  

  In today�s fast-paced digital landscape, individuals and professionals rely on various fragmented platforms to network, collaborate, and communicate. While platforms like LinkedIn, Facebook, and Slack serve specialized purposes, they fail to provide a unified space for managing both professional and personal connections. Biblo addresses this challenge by offering an integrated platform that combines professional networking, peer discovery, community interaction, and real-time communication. Built with a Spring Boot backend, Vue.js frontend, and MySQL for data storage, Biblo leverages JWT for secure authentication and WebSocket for real-time messaging. A unique feature of Biblo is its mutual matching system, which allows users to connect based on shared skills, interests, and goals, facilitating meaningful, one-on-one interactions. The platform enables users to create skill-based profiles, engage in relevant communities, and communicate instantly, all within one cohesive system.
  This thesis explores the design, development, and evaluation of Biblo as a comprehensive solution to the fragmentation of existing digital platforms. The platform combines state-of-the-art technologies to ensure scalability, security, and a user-friendly experience. The implementation of the mutual matching system empowers users to discover compatible peers through a swipe-based protocol, ensuring that connections are based on mutual interest. By utilizing JWT for stateless authentication and WebSocket for real-time communication, Biblo ensures privacy, security, and seamless user interactions. The goal of this project is to demonstrate how an integrated platform, enhanced by a peer-matching system, can foster professional connections, facilitate collaboration, and support community-driven engagement, ultimately creating a more efficient and connected online ecosystem.

Chapter 1?Introduction

2.1 Key Development Technology Introduction

Spring Boot:
	The backend of Biblo is developed using Spring Boot, a robust framework for building Java-based applications. Spring Boot simplifies the creation of production-ready applications, offering automatic configuration for key functionalities like security, database access, and API management.

Vue.js:
	Vue.js is used for the frontend, enabling the creation of a dynamic and reactive user interface. It allows for smooth user interactions through its component-based architecture and data binding features, ensuring real-time updates across the platform.

JWT: 
   JSON Web Tokens is employed for secure authentication, allowing users to log in without the need for server-side sessions. This stateless approach improves scalability and enhances security.


WebSocket:
    WebSocket is utilized to implement real-time communication, enabling users to send and receive messages instantly. This ensures seamless interaction between users without requiring page reloads.

Hibernate: 
    Hibernate is used for Object-Relational Mapping (ORM) to simplify interactions between Java objects and the database, reducing the complexity of database queries.
    
Maven: 
    Maven is used for project management, ensuring that all dependencies are handled efficiently and that the build process remains consistent across different environments.
    
Postman:
    Postman is an interface testing software that can be used for interface request testing.

3.3 Feasibility Analysis of System Tasks
3.3.1 Technology Feasibility 
    The Biblo platform utilizes Vue.js for frontend development, benefiting from its reactive data binding and component-based structure. Vue.js allows for the creation of dynamic and highly interactive user interfaces while simplifying the overall development process. Its seamless integration with Vue Router and Vuex ensures smooth navigation and state management across different sections of the application. The backend is developed using Spring Boot, a framework that streamlines Java application development by minimizing configuration and offering built-in support for essential features like security and database interaction. Spring Boot provides a robust, scalable, and maintainable backend architecture.
    For data persistence, MySQL serves as the relational database management system, ensuring reliable storage of user profiles, messages, posts, and community data. The system uses JPA (Java Persistence API) for object-relational mapping (ORM), and Hibernate is employed as the ORM provider. This enables seamless interaction between Java objects and database tables, simplifying complex database operations and ensuring data integrity. WebSocket technology is used for real-time messaging, allowing users to engage in live communication with minimal latency.
    
3.3.2 System Security Analysis
    In Biblo, user authentication is a critical component, ensuring that only authorized users can access and modify their data. The system employs JWT (JSON Web Tokens) for secure, stateless authentication. When a user logs in, a JWT token is generated and used to authenticate subsequent API requests. This eliminates the need for server-side sessions, enhancing scalability and performance. During the login process, Spring Security is used to protect the application from unauthorized access, ensuring that only valid users can perform actions within the platform.
    User passwords are securely encrypted using BCryptPasswordEncoder from Spring Security, preventing sensitive information from being exposed. When users interact with the backend, the JWT token is included in the HTTP header of the requests, ensuring that each action is authorized and the user's identity is validated. The system checks the validity of the token on the server side to prevent unauthorized access to protected resources. If the token is valid and hasn�t expired, the user is granted access to their designated roles and can perform actions within the system. This method strengthens the overall security of the platform by safeguarding user credentials and providing fine-grained access control.

The architecture is designed to facilitate a clear separation between the front-end and back-end components, ensuring modularity and scalability. 4.1 System Framework
4.1.1 MVVM package
	MVVM

    Fig:4.1 MVVM diagram
    MVVM is short for Model?View, ViewModel. It is essentially an improved version of MVC (Model?View?Controller). Model refers to the data transferred from the back end. View refers to the page you see. ViewModel is the core of the MVVM, which is the bridge between the view and the model. It has two directions: one is to convert Model into View, that is, to convert the data transferred from the back end into the page you see. The implementation method is: data binding. The second is to convert View to Model, that is, to convert the page you see into back-end data. The implementation method is: DOM event listening. These two directions are implemented, and we call them bidirectional data binding.

6.1.2 Testing plan
    In crafting the testing plan for black-box testing, our primary objective is to comprehensively assess the functionality of the software system without delving into its internal mechanisms. This methodology treats the software as a closed black box, emphasizing the inputs, outputs, and overall system behavior rather than its internal structure or workings. The testing process is centered around the program's interfaces, with a keen focus on verifying if the program operates in accordance with the requirements outlined in the specification document. Our testing will meticulously examine the program's ability to receive input data correctly and generate accurate output information. By concentrating on the external structure of the program and disregarding internal logic, black-box testing is geared towards evaluating software interfaces and ensuring that all functionality operates as intended from an end-user perspective. This approach is crucial for identifying potential discrepancies between expected and actual system behavior, ultimately ensuring the software's reliability, functionality, and user satisfaction.
